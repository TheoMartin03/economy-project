# UK Income Inequality

An analysis of income inequality and social mobility in the UK using publicly available data.

## Overview

This project investigates patterns of income inequality and social mobility across different regions of the UK. It explores how economic outcomes vary geographically and how these patterns relate to socioeconomic factors.
